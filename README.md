# Eynis Platform

Monorepo foundation for the Eynis intelligence platform.

## Workspaces
- `apps/api`: backend API
- `apps/web`: management and staff web app
- `packages/shared`: shared domain types and utilities

## Quick Start
1. `npm install`
2. `npm run build`
3. `npm run test`
4. `npm run dev -w @eynis/api`
