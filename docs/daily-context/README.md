# Daily Context Log

This folder preserves execution context day by day so development remains consistent and resumable.

## File Naming Standard
- `day-01.md`
- `day-02.md`
- `day-03.md`

## Required Sections Per Day
1. Goal for the day
2. Planned tasks
3. What we implemented
4. What worked
5. What did not work
6. Fixes and decisions taken
7. Validation and test evidence
8. Pending items
9. Plan for next day

## Rules
- Update the file at end of each working session.
- Keep entries factual and short.
- Include exact commands run when relevant.
- Record blockers and how they were resolved.
